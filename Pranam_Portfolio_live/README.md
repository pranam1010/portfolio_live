# Pranam P Gowda — Developer Portfolio

A dynamic, responsive developer portfolio built using technologies already listed in my technical skills.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Responsive Web Design

## Features

- Animated loading screen
- Dynamic typing hero text
- Scroll reveal animations
- Animated developer terminal
- Floating background elements
- Responsive navigation
- Active navigation tracking
- Interactive skill filtering
- Project showcase
- Certifications section
- Contact links
- Responsive mobile layout
- Reduced-motion support

## Run

Open `index.html` in a browser.

No Node.js, React, or backend is required.

## Customize

Edit the content in `index.html`.
Change colors, spacing and animations in `style.css`.
Change interactions and dynamic behavior in `script.js`.
